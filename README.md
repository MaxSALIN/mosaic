# mosaic-a13

The goal of this project is to code the mosaic game. Starting from the base of the code with game.c or game_aux.c.
Also, making the implementation of the project is important task of the project.

Members of the team: Occelli Thomas-Bruno, Vigier-Lafosse Matthieu, Salin Maxence

How to play the sdl version:
    -start a game with ./game_sdl with or without loading a game
    -press right click to change your current color (the current color can be seen on the current rectangle on the right)
    -press left click to play a move on a cell
    -the number on the playable cells will change color :
        -red = the current number has an error
        -blue = the current number is not satisfied
        -green = the current number is satisfied
    -to restart a game, press the key 'r'
    -to save a game, press the key 's'
    -to get the possible solution of the current game, press the green button called "solve" on the right
    -to undo a move, press the left key or the left arrow on the screen
    -to redo a move, press the right key or the right arrow on the screen

Have fun!
